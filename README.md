# G123R HoldToAB Mod

**v1.0.2** · by **WizzStar** · [GitHub](https://github.com/WizzStar/PKMN-G123R-HoldToAB-Mod)

Hold **A** or **B** to auto-advance text — no more mashing. Works in Red/Blue/Yellow, Gold/Silver/Crystal and FireRed/LeafGreen/Ruby/Sapphire/Emerald.

> 🆕 **Fast-forward proof:** held A/B now repeats at the same pace at every GAME SPEED. Fast-forward speeds up the game, never the repeat.

## ✨ Features
- **Text** — hold A or B on dialogue and battle text.
- **Boot** — hold A from launch: straight into CONTINUE (no save: NEW GAME, stops at the first choice). Hold B to skip only the intro.
- **Save** — hold A after SAVE: answers YES and saves.
- **Nurse** — hold A on the Pokémon Center nurse: heals and lets you walk away.
- **Battle** *(off by default)* — hold A to keep picking FIGHT + your move.
- **Fast-forward proof** — HOLD DELAY and REPEAT SPEED run on real time, so the repeat never speeds up with fast-forward / GAME SPEED.
- **Safe** — stops on other YES/NO prompts, menus and the overworld; START/SELECT pause it (soft reset works).

## ⚙️ Options

| Option | Default |
|---|---|
| TURBO A/B · TURBO A · TURBO B | ON |
| TURBO BOOT · TURBO SAVE · TURBO NURSE | ON |
| TURBO BATTLE | OFF |
| HOLD DELAY | 16 frames (real time, at any game speed) |
| REPEAT SPEED | 3 (1 slow – 5 fast, real time) |

## 📦 Install
Download `wizzstar_hold_to_ab_v1_0_2.zip` → launcher → **MODS** → enable. One install covers all 3 gens.
